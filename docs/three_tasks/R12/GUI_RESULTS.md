# 实时 GUI 检查结果

本轮新增的只读观测界面已通过 **14 项自动测试、21 项真实浏览器检查**。它是独立的观测功能，不改变 R10–R12 任务结论。用户手工确认仍待进行。

- 实际连接运行中的点喷任务，收到 IMU、轮速、GNSS、3D 雷达、相机、odom 六类 ROS 数据；车载相机和有界点云抽样可以显示。
- 五个页面、自动加载的运行选择、暂停/恢复界面刷新、历史任务切换、窄屏布局均经过真实浏览器检查；暂停显示期间任务仿真时钟继续前进。
- 已查看点喷实时界面、割草历史账本和巡检历史路线。巡检保留 88.48 m 原路线，同时单独显示本次选定的 20 m 范围；割草历史示例显示选定 5 段与原执行计划 47 段。
- 缺失、过期、未来时间、文件停更和历史运行分别显示；历史任务不混入当前任务的实时相机和点云。
- 重复启动时先占用 HTTP 端口，端口冲突不会额外启动订阅节点。退出只清理 GUI 自己的订阅进程。
