# R12 真实录像与交付

同一时刻只运行一辆车。录制运行器显式由当前任务运行器派生，记录源文件和派生文件哈希；仅新增隔离输出、材质、观察相机、只读录像和停车后的暂停退出顺序。原任务点/条带、地图、定位/BT/控制/工具门限不变。完整 A1/B1 可以在复验时同步录像，避免为了视频重复整簇仿真。

观察相机的实际 RGB 帧进入 ROS 域 120，仅录像节点订阅。视频按墙钟 5 fps 编码，慢速仿真会真实呈现为较慢运动；重复画面、图像年龄、仿真时钟、视频时刻逐帧保存。画面上的轨迹来自合格定位，工作量来自工具反馈数据库，不以规划线或真值直接生成完成量。真值仍只用于事后独立评分。

原片必须覆盖首次物理运动到任务终止，活动期间图像年龄不超过 2.5 墙钟秒、图像时间间隔不超过 1 仿真秒，且编码器正常退出。任务通过与录像完整是两个独立字段。失败、等待和请求人工也是真实可用的录像内容，但不能据此把完整任务记成通过。

精简版对每段原片明确标注倍速，不生成或插补机器人运动。完整原片保留，manifest 保存来源、时间线、哈希与任务结果。最终 R12 PASS 还要求 R10/R11 PASS 和三个任务的合格录像；前置未通过时保持 PARTIAL。

交付另含核心行为集锦：工具故障补作、前车停车与恢复、实际绕行接回、关刀转场等按事件日志选取。片段的原片起止时刻、仿真时刻、倍速及哈希写入 manifest，便于从精简片段定位完整上下文。

持续受阻录像曾出现任务检查通过、但一帧图像墙钟年龄约 3.19 秒超过 2.5 秒门限的情况。该录像保留为未合格录制；此可选案例改用 0.3 实时率重新录制，降低同步渲染负载。仿真时钟的场景、动作时限、障碍位置、速度和停车门限不变，不提高录像延迟容限。
