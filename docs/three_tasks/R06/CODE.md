# R06 核心代码

`optimization_v2/ws/src/task_platform/r06_backend/` 是实际 C++ 执行代码：

- `common.xml` 定义分层响应式优先树，树节点的名字直接说明检查目的。
- `policy.hpp` 保存阻挡计时、清除迟滞、进展检查和人工锁定；注册条件与动作节点。`choose()` 输出选中动作、原因、全部候选的资格、证据和阈值。
- `supervisor.cpp` 负责 ROS 版本/序号/时钟/新鲜度检查、周期 tick、取消确认协议、显式人工确认服务以及真实树节点状态日志。它不把 C++ BT 决策直接等同于底盘已停止。
- `policy_test.cpp` 使用同一 XML 和原生框架执行优先级、持续阻挡、同向跟随、锁定和进展故障检查。

Python：`scripts/policy_r06.py` 将原决策门限和新车/传感器/任务版本绑定到独立配置；`protocol_r06.py` 在独立 ROS 域发布声明的上下文，验证进程间消息、取消确认、陈旧消息、重放/未来时间、手工锁定与恢复；`stage_r06.py` 运行受限进程、检查正常退出、生成报告并封存证据。

任务专用导航动作与工具账本还需 R07–R09 接入。`work_credit=false` 明确共用树不拥有有效作业计量权限。
