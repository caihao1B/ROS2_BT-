## 修复与边界

本轮修复地面统计被稀疏噪声体素影响、地图匹配法线查询、以坐标原点衡量定位跳变、稀疏地标在进入多帧窗口前被丢弃、动态目标混入静态地图匹配、激光错误增量引发错误轮滑降权，以及导航恢复的参考路径版本交接。近地通道增加实际安装俯角，并在融合中使用同一完整外参。

横穿保护使用观测 CV 状态与未来过程协方差，并保留转向时的运动证据；最近 35 秒已观测活动区域形成临时避让代价，防止停在反复活动的轨迹上。它不是学习型行人意图预测。有效路径跟踪误差按当时发布并准入的参考计算，原路偏离量仍单独保留。前期原脚本行人与车辆接触、内部射线角超过 OGRE 限制等失败均未计入通过。

50 项 Python 组件检查与 25 项原生 BehaviorTree.CPP 检查用于补充真实案例，最终结果见阶段 tests.log/native_tests.json。原冻结数据库、车辆物理约束、停车确认和 GNSS 创新门限保持不变。R01–R07 原回执不改。

地图匹配 overlap 的分母现在是静态地图关联候选，同时记录原始点数及候选比例；不能把此值与原全点云 overlap 直接比较。动态点仍保留在完整避障分支。
