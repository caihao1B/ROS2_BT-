# R02 核心代码

Python `geometry_r02.py` 从几何契约生成简单 box/cylinder 碰撞体、惯量和真实车轮关节。与只更换外观不同，四轮滑移车型有四个接触轮、四个连续关节；Ackermann 有四轮和两个前转向关节。`config_hash` 绑定实际参数。

C++ `src/VehicleDrive.cc` 在原 S03 执行器上扩展差速前轮：前左速度跟随后左，前右跟随后右。原来的 session/revision/epoch/sequence 校验、双时钟失联锁止、有限加速度、转向跟踪门保持不变。阿克曼按照实际转向编码器推算曲率后计算后轮速度，零速角速度请求不会使车身原地旋转。车身位姿没有通过代码强行写入。

`driver_r02.py` 是试验输入者，只订阅时钟和编码器，依次发前进、左右弧、后退、原地转向请求。它不是正式自主导航控制器。`probe_r02.py` 分离在线域和只读评价域，管理有界运行与按本次进程收尾。`analyze_r02.py` 对稳态真实轨迹做最小二乘圆拟合，记录半径误差、径向残差、方向、位移和停稳；道路检查沿公开中心线移动车体多边形，不使用仿真隐藏障碍提前规划。

C++ 实测必须来自编译后的 `libr02_drive.so` 与真实 Gazebo；仅 Python 理想运动学测试不计 R02 通过。六项静态契约测试补充检查：版本、真实四轮、转向限位、扫掠轮廓、真值隔离和零速旋转契约。
