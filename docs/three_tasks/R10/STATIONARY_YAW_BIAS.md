# 点喷车辆停车期间的陀螺零偏跟踪

在 11 月 15 日的完整 A1 试验中，点喷车在第 29 个服务点停车后，独立地图观测三次触发 0.035 rad 的原始旋转跳变保护。对应捕获时刻与配对里程计的时间差均约 0.010 秒。1338–1344 仿真秒之间，轮速器的平均角速度接近零，经过启动标定的陀螺仍给出约 −0.005 rad/s 的平均角速度。1391–1402 秒之间的偏差达到约 −0.008 rad/s。持续积分这种偏差，会使局部里程计在车体停止期间累积航向变化。

仿真 IMU 模拟了零偏随机游走。原输入适配器使用启动后第 1–4 秒的观测估计偏置，并在之后一直沿用初值。新点喷适配器保留了这次标定，并在后续多次有证据的停车期间估计剩余的 Z 轴角速度偏差。[上一版本运行证据](../../../validation/R10/bounded_A1_heading_transitions.json)

## 估计器怎样判断停车

1. 在 IMU 样本的采集时间向前查找轮速和控制出口数据。轮速最多落后 0.08 秒，控制状态最多落后 0.15 秒。真实控制消息必须报告 STOP、零速度请求、导航空闲和车体已停。
2. 轮轴测得的线速度绝对值须小于等于 0.012 m/s，角速度绝对值须小于等于 0.010 rad/s。输入层出现打滑判定，或新鲜独立位移观测已否定轮速时，暂停学习。停车方向相同的微小转动通过测得的轮速角速度扣除，以减少把真实转动当作偏置的风险。
3. 连续满足条件 0.6 秒后，按 4 秒时间常数更新偏差估计。单次输入残差及它相对当前估计的差值均须在 0.020 rad/s 内。超界、采样间断及停稳证据过期会中止更新，已估计的偏差可继续用于行驶。重复或倒序的采样时间不计入更新。上层重置定位时，从新时间段重新标定。
4. 输入适配器将修正角速度交给原来的轮速、IMU 与激光局部里程计。车体的停车判定、作业许可、GNSS 创新、地图跳变、点喷目标误差和作业确认分别沿用各自的检查。

本方法只读取运行中的传感器和控制回执。若车辆在车轮锁止时受到外力推动，且独立观测不能分辨很小的滑转，零偏和微小转动仍可能混淆。停车证据门限、轮速创新检查和残差上限限制了这种情形下的学习范围。[估计器实现](../../../optimization_v2/ws/src/task_platform/scripts/stationary_gyro_r10.py) · [生产 ROS 输入适配器](../../../optimization_v2/ws/src/task_platform/scripts/spray_inputs_r10.py)

## 怎样复验

从机器人项目根目录运行。第一条命令载入 ROS 2 Jazzy 与本机工作空间。单元测试检查实际转动保留、旧时间戳、失去停车条件、轮速打滑和大偏差信号。ROS 检查会在单独的本机通信域 173 启动一个真实输入适配器进程，给它发送人工构造的 ROS 消息，再从输出话题读取角速度。它会自行结束。

```bash
cd /home/ceihao/robot_project
source optimization_v2/env.sh
python3 -m unittest discover -s optimization_v2/ws/src/task_platform/tests -p test_stationary_gyro_r10.py
/usr/bin/python3 optimization_v2/ws/src/task_platform/scripts/probe_stationary_gyro_r10.py
```

如果本机有上一版本完整 A1 的原始数据，可以用下面的命令复算两个真实停车区间。命令只读旧记录并将结果打印到终端。

## 达到重定位次数上限时怎样计分

旧运行最终确认底盘及工具均已停止，39 个进程中 38 个返回零，余下的任务观察器使用退出码 2 表达点喷业务失败，导致外层把本次运行也记为退出失败。现行点喷任务保留业务失败及残余。当原因明确为重定位次数耗尽，并且收到工具 STOPPED 确认、最后一次双停反馈在 0.15 仿真秒内、也无关闭异常时，观察器可正常退出。完整任务的判定仍读取点位、剂量及独立评价。这样可以分别排查“为何没有完成点喷”和“系统是否确实停干净”。[点喷任务观察器](../../../optimization_v2/ws/src/task_platform/scripts/mission_spray_r10.py) · [现场数据评分器](../../../optimization_v2/ws/src/task_platform/scripts/analyze_spray_r10.py)
