# R11 材质细化与真实性边界

三种底盘共用原地图，点喷蓝色、巡检橙色、割草绿色。通过 PBR 材质和程序生成面板纹理表现面板、通风口、紧固点及轮胎橡胶，不引入高面数网格。喷洒区使用土色，割草区使用草色，连接路采用灰色；原低矮障碍、坡面和动态物体仍在原位置。

本版只允许修改 SDF 的 visual/material。删除材质节点后对整棵 XML 做规范化哈希，要求修改前后完全一致。这比只比较 collision 更严格：visual geometry、传感器位置和视场、惯性、关节、插件、噪声设置均受保护。材质改变摄像头像素，因此不能声称传感器输入完全相同；录制阶段重新运行真实感知、定位、控制和工具流程。

性能对照：每辆车分别运行原始/材质场景，使用相同 960×540、8Hz 观察相机、相同 Gazebo 种子和 0.4 实时率。剔除前两秒，测量到第十个仿真秒的实际收帧时间，计算仿真时间/墙钟时间。要求相对实时率至少 0.8，所有进程正常退出。该测试是停车渲染、且受 0.4 设定上限约束；不等同于峰值 GPU 性能或完整运动任务通过。

观察相机仅用于演示，ROS 域 120；导航和控制仍在 119，原始传感器域 121。原始模型、地图和冻结数据库不被材质生成器覆盖。
