# R07 实测结果

当前配置的正常与工具故障案例均通过，15 项组件检查通过。阶段回执封存后可进入 R08；此 PASS 的范围是下述任务组件集成。

正常案例：`spray_20261114_055803_663083`。原 A1 顺序中的前三个点真实完成，任务用时 85.742 秒仿真、237.021 秒墙钟（包含启动和退出）。地图定位 XY RMSE 3.59 cm；三个点实际喷洒位置最大误差分别为 0、6.17、6.38 cm。对应账本确认量 3.00、3.05、3.05，独立物理剂量 3.130、3.180、3.181；没有超计。这是仿真服务单位，不代表实测药剂升数。

第二点发生一次几何保护停车并在观测恢复后继续；第三点发生定位准入等待、取消和恢复。第三点停车后复核误差为 11.58 cm，未直接开始喷洒；真实重新停靠后复核为 5.74 cm，再通过原工具 8 cm 检查完成工作。相同幂等键重放没有新增流量。

没有非预期车体接触；底盘、工具及两个 TF 边保持唯一发布者。任务结束实测车体与工具停止，全部进程正常退出，原 RTAB 数据库哈希不变。在线节点未订阅真值。

15 项组件检查通过，覆盖原任务义务/阈值、版本拒绝、SQLite 重启保护、生产输入适配器时间窗口/滑移判据、生产 C++ 地形观测、实测平面基线、真实 Nav2 未知区域保留、点服务目标检查器和实际规划器。规划器测试输出 62 个路径点，最大间隔 0.049674 m、精确目标 (1.03,0.02)，被占据目标返回 ABORTED；这些组件检查不替代真实导航与工具集成。

本步骤验收三点任务组件闭环。A1 原总计 56 点，未选 53 点明确保留；A2/A3 点序、原正式任务及 S17/S18 历史状态不变。完整簇、全地图定位、长期阻塞与真实打滑组合未验收，不能据此宣布 A1 或 30 分钟整簇指标完成。

## 同版本工具故障与部分完成重试

案例 `spray_20261114_060233_437361`：105.666 秒仿真、282.759 秒墙钟，定位 XY RMSE 2.87 cm。第二点在 42.63 秒注入真实工具 JAM，报告 `TOOL_HEALTH` 后停止，健康恢复并再次确认停靠后补做成功。第三点已确认 1.60 单位时发生 `NOT_DOCKED`，保留 1.40 单位残余；实际重新停靠后使用同一任务键续作，最终确认 3.10，没有清零或重复记入原已确认量。三个点的独立物理剂量为 3.233、3.259、3.413，最大实际喷洒位置误差为 0、5.28、6.26 cm。工具升速/停止过渡中的实际流量可能不获得有效作业信用；这是保守账本，不是实际药液剂量闭环的认证。

两个案例均无非预期接触，唯一出口、数据库不变、实测停止、无强制终止退出及源码/任务版本绑定检查全部通过。故障后只补做已确认账本的剩余量；此案例也实际覆盖了非零部分完成后的恢复。

## 保留的失败与修复

诊断运行保留在各自独立目录。主要问题包括格心目标偏差、异步反馈配对、地面点主导 ICP、增量时间窗与轮速失配、近地盲区、单点地形噪声、近车体坡度不可观测、短暂取消被误记为持续导航失败、终端朝向锁存后位置漂移以及过稀直连路径。上述修改均位于 R07 新版本，原 S05/R05 等历史实现与回执未覆盖；旧配置曾通过的单次正常案例不能作为当前版本准入依据。
