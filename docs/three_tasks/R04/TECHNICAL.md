# R04：轻量底盘动力学与速度资格

R02 的四轮差速车采用真实轮胎接触，不能把几何轮距直接等同于侧滑后的有效轮距。使用 R02 的双向圆周观测，计算有效驱动轮距 T_eff = T_geometry × ω_command / |ω_measured|。修改的是新版本轮速映射参数，不改变车体、轮胎几何、质量、摩擦、转向限位或原停车阈值。编码器反算与轮速驱动使用同一有效轮距，避免一端校准、另一端仍用旧参数。

校准样本为 R02 的 0.4 m/s、曲率 0.8；R04 用未参与校准的 0.6 m/s、曲率 0.45（Dino 为 0.25）左右转验证，再用 -0.25 m/s 倒车弯道检验符号和运动学。这是当前 Gazebo 平地摩擦模型的校准，不能迁移为草地、泥地或厂家硬件标定。

分别执行 0.3、0.6、0.8 m/s 的前进加速和停车，检查真实车身速度、受限命令的加速度、实际停车延迟与距离。平地候选最高 0.8 m/s；任务转场暂选 0.6 m/s，点喷 0.4 m/s，割草 0.5 m/s，倒车 0.25 m/s。完整导航还必须通过 R05 传感器/定位以及 R06–R10 的通行与行为检查；原入口的低速限制不修改。

故障顺序是：0.8 m/s 行驶 → 停止发送命令 4 秒 → 发送 DRIVE 但不 ARM → 明确 ARM → 恢复行驶。底盘内部看门狗应停车并锁存，单独恢复 DRIVE 不得自动重新运动。仍使用原 0.35 秒执行器看门狗和 2 秒停车上限，没有为通过验收扩大门限。

理论停车距离预算为 v²/(2a_brake)，断流再加 v×0.35 秒看门狗延迟，并留 0.10 m 采样/接触余量。最终门槛以 Gazebo 实际车身位姿求速度、积分停车距离，不能只检查命令已经归零。

R03 的倒车条带连接仍保留停车、换向和工具关闭语义。R04 只检验平地底盘能力，不表示这些整条覆盖路线已经由导航控制器走通。坡度、湿滑地面、力矩/电池功率限制和完整作业耗时不在本步 PASS 范围。
