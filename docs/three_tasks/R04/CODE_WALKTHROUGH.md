# 核心代码逻辑

Python `dynamics_r04.py:build` 读取 R02 的真实圆周结果，推导新的有效轮距，生成带新哈希的 R04 配置。`phases` 定义独立留出工况与断流故障；`evaluate` 从隔离的评估域读取车身真值，以有限差分得到实际速度/角速度、最小二乘圆拟合得到转弯半径，检查停止距离、时延和锁存状态。

Python `probe_r02.py` 是冻结的公共物理探针。R04 只传入新配置和工况，不修改它或 R02 结果。在线 `driver_r02.py` 只订阅时钟和编码器，用 session/revision/epoch/sequence 构造命令租约；评估真值不进入控制。

C++ `src/VehicleDrive.cc` 沿用 R02 版本：差速左右轮角速度为 (v∓T_eff·ω/2)/r，前后同侧轮一起驱动；阿克曼通过轴距/轮距求左右前轮转角，以实际转角反馈计算实际曲率。每个仿真步限幅加减速和转向速率，超过看门狗时锁存停车。代码只写轮关节速度，不直接设置车身位姿或速度。

R04 使用原 C++ 实现而不复制第三份底盘执行器。新的功能是物理参数识别、独立验证、速度资格输出和故障证据。4 项单元/契约测试检查几何与安全参数保持、驱动/编码器校准一致、故障时序以及计划速度位于候选范围。
