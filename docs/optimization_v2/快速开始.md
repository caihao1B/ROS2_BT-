# 当前开发机快速开始

工作根目录：`/home/ceihao/robot_project`。本轮交付 S18 的独立部分，S17 仍未通过全矩阵。当前入口支持人工逐项验证，不代表整套全地图任务已验收。主项目不依赖已移除的新加卷目录。

```bash
bash /home/ceihao/robot_project/optimization_v2/run.sh --help
bash /home/ceihao/robot_project/optimization_v2/run.sh doctor
bash /home/ceihao/robot_project/optimization_v2/run.sh status
```

`doctor` 检查已注册地图、计划和绑定输入；`status` 快速读取回执状态，不重复哈希全部历史证据。完整新审计使用 `run.sh audit`。

三个任务入口均使用原正式地图/计划，默认有界试运行。一次只运行一个；默认无 GUI，添加 `--gui` 打开 Gazebo。短时间未完成任务时返回码 2 并保留 PARTIAL/FAIL，不能把退出码改成通过。

```bash
bash /home/ceihao/robot_project/optimization_v2/run.sh spray --cluster A1 --sim-seconds 180 --wall-timeout 540 --gui
bash /home/ceihao/robot_project/optimization_v2/run.sh mow --cluster B1 --sim-seconds 180 --wall-timeout 540 --gui
bash /home/ceihao/robot_project/optimization_v2/run.sh inspect --vehicle diff --sim-seconds 180 --wall-timeout 540 --gui
# 巡检另一底盘：把 --vehicle diff 改为 --vehicle ackermann。
```

停止时在另一个终端执行：

```bash
bash /home/ceihao/robot_project/optimization_v2/run.sh stop
```

停止命令校验本会话 PID、启动标识和所有者；不终止别人的 ROS/Gazebo。每次运行路径打印在首行，并保存在 `optimization_v2/results/S18/last_run.json`。原 S17 执行器的数据布局要求案例位于 `results/S17/release18_*`，其结果不写入正式矩阵，也不更新 S17 回执。

恢复只接受本入口产生、已有安全与定位评分且停车/工具关闭确认的作业案例；禁止恢复不确定账本。将 `实际运行目录` 替换为打印路径：

```bash
bash /home/ceihao/robot_project/optimization_v2/run.sh resume --from-run 实际运行目录 --sim-seconds 180 --wall-timeout 540 --gui
```

此统一入口的巡检后缀恢复暂未资格验证，会明确拒绝；旧演示的恢复仍使用其原有入口，不能混用正式和演示计划。

现有系统软件由 `/opt/ros/jazzy`、系统 apt 包及项目隔离 venv 提供；旧 S01 依赖锁是历史安装记录，本轮实际版本在 S18 报告的 `system_packages.tsv`。已构建地图/定位资源不可当缓存删除。新机器全量安装构建和路径迁移仍未验收，因此本文件是当前开发机入口，不是可移植安装成功承诺。
