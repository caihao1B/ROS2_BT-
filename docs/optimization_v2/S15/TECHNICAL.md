# S15 技术原理与边界

本步在 S14 已验收版本之外增加动态预测与风险监督，不修改 S14 源码、区域地图、GNSS 配准或原始作业分母。生产运行入口为 `optimization_v2/stepctl.sh`。本步动态闭环范围是同一 A 区部署点的差速车两点喷洒基准；完整 A1/B1 仍由 S14 证据支持，六簇和阿克曼动态条带恢复留待其对应阶段。

## 输入与职责

`/s09/objects` 来自带误差的 3D 激光几何聚类、真实相机 NanoDet 检测、双目深度一致性和目标关联。输入坐标为 odom，时间来自仿真钟。confirmed 且 OBSERVED 的目标才进入预测历史；长遮挡、过期和时钟倒退不能被伪装成新观测。预测器不订阅 domain120 真值，不读取模拟演员的未来路径。冻结地图仍服务定位和当前通行判定。

历史为 8 个 0.4 秒格点，共 2.8 秒过去；插值只能用截止时间之前已经收到的观测，速度与加速度采用后向差分。邻居只允许同步、3 米内已观察到的行人。输出为未来 3.2 秒、8 个时刻的多分支位置均值、概率和 2×2 协方差。

## IMM：四种不同运动模型

共同状态为 `[x,y,vx,vy,ax,ay]`，包括 CV、CA、左右协调转弯。CV 抑制加速度状态；CA 积分速度和加速度；转弯模式用 ±0.4 rad/s 旋转速度，使用解析圆弧积分更新位置。模式转移对角概率 0.94，其余均分。

每次先计算模式先验 `c_j=Σ_i μ_i p_ij`，再按条件概率 `μ_i p_ij/c_j` 混合均值和协方差，传播各模式并用同一个位置测量更新。Joseph 形式保持协方差数值稳定，创新似然更新模式概率。没有把同源跟踪器的位置和速度当作两个独立测量重复融合。预测保留四条分支，避免用一个均值掩盖转弯可能性。

优点是低计算量、参数可解释、缺少训练数据时也可使用；局限是固定模式集合和过程噪声不能表达所有人类意图，CA 长时域协方差会迅速增长。

## Trajectron++：真实固定权重适配

采用 StanfordASL 官方 ECCV 代码提交 `ef0165a93ee5ba8cdc14f9b999b3e00070cd8588`，MIT 许可，`eth_attention_radius_3/model_registrar-100.pt`。完整 SHA256 与逐文件来源见 `optimization_v2/config/model_lock.yaml` 和 vendor/upstream_files.json。

历史 LSTM 与邻居边编码产生条件表征，离散潜变量为 N=1、K=25，GRU 解码速度分布，经 SingleIntegrator 积分成未来位置分布。保留真实混合权重和协方差，额外加入观测位置协方差；不把 25 条轨迹设成等概率。该权重没有地图编码、没有机器人未来编码，也没有在本项目中重新训练网络。

Python 3.12 / CPU PyTorch 2.6.0 独立环境，仅一条计算线程。显式兼容适配包括 `collections.abc.Sequence`、Distribution 形状元数据和可信固定哈希的旧 ModuleDict 加载。只跳过最终完全不用的 0.01 m 众数网格搜索；逐步解码、分布和已训练参数不变。组件测试实际比较了分布数值完全一致，检查加载后没有偷偷创建随机模块。

模型擅长表达多种可能未来和邻居影响，但 ETH 行人与农田刚体行走姿态存在域差异；类别闪烁和观测噪声也会影响效果。非行人使用明确标记的 IMM 回退，不能把它记成神经网络推理。

## 风险、BT 与控制

预测器通过有界非阻塞管道交给独立 C++ 风险监督器。展示及评分仍使用全部 3.2 秒，制动判断只使用前 2 秒，并限制预测协方差最大标准差 2 米。机器人短时意图来自有界导航速度与角速度；按圆弧传播，使用完整底盘外接圆半径 0.66 米、目标半径、0.15 米余量、95% 协方差包络及采样间隔余量检查相交。

风险量是“与运动包络相交的模式概率质量”的保守代理，不是已校准的真实碰撞概率；也没有宣称 Nav2 原生二维代价图有完整时间维。达到 0.35 时停车并向 BT 提供 `PREDICTED_CONFLICT_WAIT`，达到 0.15 时最多 0.06 m/s。预测只能降低原 0.12 m/s 上限。

S15 Policy 组合原 S14 Policy，只在原判断为 EXECUTE 时加入预测等待。当前真实障碍、定位/观测失效、工具不确定、预算不足和 watchdog 保留原优先级。一次等待仍最多 45 秒，恢复需 1 秒稳定条件、当前代价图、底盘静止和工具停止反馈；观测恢复与预测恢复合计最多 12 次，原 2 次重规划、3 次延后和停车预算不扩大。点作业沿用原幂等键和账本，取消不新增作业信用，已确认量可恢复补足。

250 毫秒推理超时、通道失联、坐标错误或过大不确定度退回当前观测安全基线。预测通道不拥有底盘执行器，也不能解除独立停车条件。真实持续异常仍可能安全中止任务，这不是完成任务。

## 数据与评估

训练、验证、测试按整个场景/轨迹 episode 分开，每组各含转弯、停走、脚本让行和遮挡，改变演员位置、速度时间尺度及轨迹幅度。这里的 train 用于域统计与不确定度校准诊断，明确没有微调神经网络。未来标签由独立离线评分器从未来观测构建；遮挡时间过长不跨空缺插值。独立真值仅作审计，不写入在线特征。

主指标为概率加权 ADE/FDE、混合密度 NLL、矩匹配 95% 椭圆覆盖率；minADE/minFDE 仅为事后最佳分支辅助值。闭环记录安全、两点完成、预测等待、重规划、实测时间、延迟、CPU 和内存。风险漏报诊断对照实际未来观测与当前机器人足迹，分母为 0 时显示 N/A，不能记成 0% 漏报。

默认选择依据 `prediction.yaml` 中测试前冻结的门槛。学习候选失败时保留真实模型及失败结果；IMM 也没有充分收益证据时，允许维持原无预测基线，不为宣称优化而强制启用。报告的阶段验收与模型收益门槛是不同结论。
