# S12 点服务、条带路径与工时闭环

本步将 S11 的候选分簇转换为可复查的离线运动计划。`VALIDATED` 的范围仅是授权先验上的几何、运动约束及时间模型；`online_execution_allowed=false`。没有运行 Gazebo 任务，不能将规划足迹称为实测割草面积。当前结果与数字见 [RESULTS.md](RESULTS.md)。

## 1. 输入、范围和版本

使用 S02 `maps/prior` 的连续工作区、永久设施、道路，S03 车辆/工具外形及已验证能力，S08 定位限速与测量配准，S10 有效作业门限，S11 候选任务及分簇函数。不会读取未知障碍或动态对象未来真值。单位为 m、rad、s；路线坐标为 `prior_local_enu`，不直接改名为 SLAM map。导出独立场地控制点计算的 `map ← prior` 刚性变换；既有连接路/B 区非刚性地图变形仍是后续在线限制。

速度取 `min(S03 selected_work_mps, S08 nominal_speed, S10 work_max_speed)=0.12 m/s`。没有把底盘高速测试结果当成作业许可，也没有改旧阶段配置。

原 A 区约 1645.98 m²、407 个点，B 区约 1120 m²。整区在当前速度下无法满足三簇预算。喷洒按固定朝向、2 m 网格、忽略返程/转向/启停的乐观下界为 `(N-3)×2/v + N×驻留时间`；割草在直线条带模型下的乐观值为 `0.95×面积/(0.9×v)`。这只是本任务与条带模型下的下界，不是任意机器人运动的通用定理。

执行批准任务书允许的显式任务改版：在原区域中心按候选 `[0.40,0.25,0.20]` 缩放连续多边形，再扣除原位置永久设施，逐个重新做算法三分簇。最大 3 个尺寸 × 3 次反馈；重复划分提前终止。选第一个可行尺寸，再在该尺寸内选最大簇时间较低的方案。原世界、原分簇产品、原任务分母保持不变；本版新目标、原目标、未纳入范围分别导出，未纳入范围不算完成。原区仍为合法转场/转弯空间，工具轨迹必须在原授权区域内。

## 2. A 区点服务

机器人保持既定停靠朝向，车体参考点位于服务目标后方 0.42 m。先把原运动区域按完整车体/工具外接半径加余量内缩；任务停靠点和安全边界顶点构成可见图，连边必须整段被安全区包含。Dijkstra 得到真实绕障距离矩阵，不能跨孔洞连欧氏直线。断开或不可达时返回明确错误，不能删点后报完成。

NN + 2-opt 是简单基线；候选调用安装的 C++ OR-Tools `RoutingModel`，毫米整数代价、最便宜弧初解、贪心局部改进、2 s/1000 解上限。两者都不是全局最优证明。把两种顺序分别展开成真实直线/差速旋转/停靠动作，再按累计工时选较低方案：距离更短不一定总时间更短。

每个点计入 1 s 停靠、1 s 工具启动、2 s 服务、2.5 s 关闭；真实执行以后仍必须等待 S10 反馈，计划驻留不能直接生成已完成账本。

## 3. B 区条带和地头

实际调用 Fields2Cover 2.1.1：`ConstHL → BruteForce(NSwath) → BoustrophedonDecomp/Order → DubinsCurvesCC 或 DubinsCurves`。候选角步长 15°，条带间距 0.65 m，整区地头宽度 4.22 m。以整区统一条带相位生成，再按逻辑簇裁剪，簇边界不重新留一圈地头。几何分解用于记录和检查非凸/含孔形状，统一相位避免分解单元之间漏缝；最终连接顺序由有界、考虑可行转弯的贪心选择决定。

工具有效足迹沿用 S10 的 0.7 × 0.9 m 矩形和 +0.5 m 偏置，按位置/yaw/账本精度侵蚀约 0.0793 m。只累计计划速度 ≥0.02 m/s 的工作样本；0.65 m 行距小于侵蚀后的有效宽度，端点外延 0.35 m 保障停车减速前的边缘覆盖。完整物理包络另行验证，不能把有效刀幅当成碰撞体。

整个任务区的边缘、地头、凹角均属于覆盖分母。小尺寸 B 任务的 4.22 m 地头内缩可能使其大部分或全部成为地头；仍用全区直线条带完整覆盖，不把地头删掉。区域外的安全转弯允许借用原作业区，工具关闭。簇边界存在有限重叠，覆盖用几何并集计数，不能重复累加。

连接只允许向前运动，最小半径 2.11 m。优先比较 F2C 连续曲率和普通 Dubins 候选：前者转向连续但可能有较长回转环；后者通常较短，但曲率跳变处必须停车、用实测静止确认后调整转向，再启动。该事件输出为 `steering_events`，计入工时与转向角速度 0.6 rad/s 约束。禁止把普通 Dubins 的曲率跳变当成移动中瞬时转轮，也禁止阿克曼原地转车身或倒车。

## 4. 独立包络与时间计算

每段用车体和工具外形的凸包，沿离散位姿扫掠。每个采样外扩 `0.08 + 0.002 + max(Δs+r|Δθ|)/2` m，以保守覆盖样本间的平移与转动。圆角多边形半径再除以 `cos(π/16)`，补偿有限离散圆弧可能内缩的误差。检查原运动区域包含整个包络，并记录实际最小几何净空、失败采样位置、最大曲率、朝向与速度方向误差。差速旋转独立检查；阿克曼零位移大角度变化立即拒绝。插值只合并位置和朝向都相同的重复状态。

速度前向限制 `v[i+1]² ≤ v[i]²+2aΔs`，后向限制 `v[i]² ≤ v[i+1]²+2dΔs`，每段及转向跳变点速度为零。加速度 0.5 m/s²、减速度 0.8 m/s²；采样间积分 `Δt=2Δs/(v[i]+v[i+1])`，短距离两端均为零时使用三角/梯形速度积分。差速角速度使用角加减速梯形；阿克曼用内侧转向关节角验证转速，不能只验中心虚拟转角。

`T = 1.15 × (运动+转向停车+工具启停+点服务/停靠+10 s 任务准备)`。

每簇名义 `T ≤1440 s`；运行上限 1800 s 留给动态等待、局部修补、停车和保存。15% 是预算余量，不是已测出等待时间。连接路含两端进出停车点，按双向/两种车分别导出独立巡检任务，不悄悄加入簇时间。

## 5. 工时反馈与计划准入

每簇路线回算工时按 S11 原单元工作量比例分摊，得到新节点权重，再调用 S11 连通边界交换。单元迁移必须保持供给簇连通、接收簇真实相邻；固定三簇。此处是近似归因，不声称每个单元的精确边际转弯代价。每次重新生成路线、验证几何并集/重叠/邻接/点归属及预算，不能仅因权重更均衡就通过。

任务几何、地图、车辆、工具、定位门限、规划配置、依赖锁、生产源码及二进制全部绑定哈希；更改任一关键输入后旧计划拒绝。修改计划正文即使未改版本号也会被检出。最终导出的计划还须经独立重算、失败用例和真实浏览器交互检查，才发布到 `plans/validated`，manifest 最后写入。下游仍须检查 S12 有效回执。

## 6. 技术选择的边界与后续接入

- NN+2-opt 易检查、快，但可能局部最优；OR-Tools 功能成熟，当前依然是有界启发式，按实际工时比较后选用。
- Fields2Cover 负责覆盖几何；完整车体包络、三簇工时、工具反馈和实际执行不由库自动保证。本步保留失败转弯，不隐藏失败样本。
- 停车转向缩短某些回转但增加启停和运行协议要求。后续 S13 必须实现这些停车事件或拒绝含该事件的路线，不能直接把整条折线路径交给 FollowPath。
- 主线是离线完整义务 + 在线局部修补。遇临时障碍先停/等/局部重规划，长期变化只对未完成工作重分簇并重新版本化。纯在线覆盖作为 S17 对照；两者都以同一个已冻结任务分母、同样传感器与工具能力评分，不先宣称哪种优越。
- 先验允许区域不能替代 S09 低障碍/坡度/动态代价。实时定位误差、打滑、避障耗时和工具不响应均未在 S12 实测；S13/S14/S17 必须分别闭环验证。
