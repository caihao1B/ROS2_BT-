# S18 技术说明：独立部分交付

2026-11-14 用户授权优先推进可人工验证的交付部分。S17 正式矩阵和完整巡检仍有缺口，S18 不宣称最终通过。单独的依赖/学习/存储工作可先完成；自动通过、人工待验、未实现、未实测分别记录。

统一入口复用冻结 S17 的地图版本准入、每案例隔离进程、唯一下发链、真值隔离及独立评分；不重新实现底盘与导航。三个功能入口分别选择差速点服务、阿克曼条带、指定底盘巡检。恢复额外核对安全与定位评分，禁止从只拥有最后姿态的失败案例恢复。

审计按文件去重后哈希一次，检查原回执源码/证据和前置引用；相比递归重复计算，它保留文件级核查并减少重复 I/O。系统 apt 安装与项目内地图/模型资源分别列出。干净 shell 验证指当前机器现有依赖下的入口复现，不等于干净机器全量重装。

存储组件只接受新建的受控目录。入库前检查登记文件、内容哈希、受保护列表、容量与数量；不能清理未知文件或符号链接。新载荷不能容纳时先计算可删除集合；受保护项阻止轮转则拒绝写入，禁止用删原始地图满足配额。现有老录制器尚未全部接到此组件，整体案例 1 GB 上限仍未完成集成。

本轮新增前方障碍距离跟随的离线控制核心：同向目标筛选、净间距、限速建议、停止/丢失目标保护与清空滞回。当前限定短直线通道，使用观测轨迹；没有 ROS/BT 在线接入，不发布底盘命令，不产生已完成作业证据。弯道、视觉新外形和真实数据闭环须另行资格验证。


跟随速度提案使用车体边界净间距 `g`：目标距离 `g*=max(1.2+2v, 0.7+0.4v+v²/(2×0.5))`，速度建议 `clip(v_leader+0.35(g-g*),0,0.12)`。距离减去目标投影尺寸、车头长度和两倍观测标准差。这个参数组只是保守实验起点，不是商业安全认证。目标 ID 丢失、协方差非法、横穿或逆向变化均要求停车，不重新盲选另一个人。ROS 接入还需 BT 状态与唯一速度出口联锁：Nav2 SpeedLimit 的零值表示取消限速，不能直接用零值请求停车。

外观生成先修改隔离 SDF 的 visual，剥除全部 visual 后规范化 XML、比较 SHA-256，保证碰撞、惯量、关节、传感器和插件配置未改。程序化 OBJ 带面法线、草地/土壤/碎石纹理带 UV，车壳面板分层避免深度冲突。真实 Gazebo 只读观察摄像头提供预览，不能代替新外观下的感知回归。
